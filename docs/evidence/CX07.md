# CX07 - Hostile provider streams and rendering

Threat: a provider emits oversized, malformed or deceptive NDJSON/Markdown that exhausts Cortex or creates trusted-looking browser state.

Invariant: individual provider lines stop at 1 MiB, a run stops after 4,096 events or 32 MiB, stderr is bounded, and truncation is an explicit Cortex lifecycle event. The browser emits model text through text nodes; links accept only explicit HTTP(S), gain `noopener noreferrer`, and provider-reported tool shapes are not classified as trusted Cortex lifecycle state.

Evidence: focused Go tests pin stream limits and diagnostic bounds; frontend smoke checks pin safe DOM construction and trusted outer event classification. Full test, race, vet, build, JavaScript and Nift gates passed.

Retained boundary: output limits reduce resource and rendering risk; they do not make model content truthful or defeat prompt injection inside an authorized agent task.
