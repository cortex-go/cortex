# CX08 - Durable conversations, SQLite and accounting

Conversation imports are one SQLite transaction: one invalid item leaves zero imported rows. Startup resolves persisted `running` conversations and runs to `interrupted`, list/search results are capped at 250, migrations are transactional, future schemas fail closed, WAL uses FULL synchronization, and database files are owner-only.

Token and cost fields remain provider-derived usage estimates, not billing records. Focused tests cover atomic rollback, restart recovery, durable round trips, future schema refusal and usage extraction.
