# CX04 - Workspace and filesystem confinement

Threat: a browser-controlled path, restored conversation or in-root symlink reaches host data outside the configured workspace root.

Invariant: every filesystem use resolves the existing target against Cortex's canonical root immediately before use. Lexical traversal and symlink escapes fail closed. Browsing is capped at 5,000 entries; previews accept only regular files up to 2 MiB.

Evidence: `workspace_hardening_test.go` covers external symlinks, permitted in-root symlinks and restored conversation workspaces. The full test, race, vet and build gates passed.

Retained boundary: this is application-level path confinement, not an OS sandbox. OpenCode retains the operating-system authority of the account running Cortex inside the selected workspace.
