# CX10 - Installation, releases and deployment

The release workflow builds Linux, macOS and Windows archives for amd64 and arm64, requires a semantic `vMAJOR.MINOR.PATCH` tag, verifies exact archive membership and publishes SHA-256 checksums. The installer requires HTTPS/TLS 1.2, verifies the selected archive checksum before extraction, stages the executable beside its destination and atomically renames only after verification.

Release smoke checks pin checksum and staging controls, six targets and a binary/data history scan. Failed download or verification leaves the installed executable untouched.
