# CX09 - Concurrency and resource exhaustion

Cortex admits at most 128 concurrent HTTP requests and returns 503 with `Retry-After: 1` while saturated, then recovers immediately when capacity returns. Agent execution remains capped at four, SQLite at eight connections, sessions at eight, OAuth state at 128, directory listings at 5,000, conversation results at 250, browser tabs at 32, closed tabs at 20 and retained events at 500 per tab.

Focused pressure and race tests cover overload recovery and concurrent settings reads. Full race, vet, build and frontend gates passed. These are single-node safety bounds, not capacity promises for arbitrary hardware.
