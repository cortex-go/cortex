# CX01 evidence - HTTP, browser and request parsing

Date: 2026-08-27

## Verified

- The HTTP server bounds headers, header-read time, request-read time and idle
  connections. The global write timeout remains disabled deliberately because
  `/api/agent/run` is a streamed response.
- The typed route inventory enforces declared methods and emits `405` with
  `Allow`; bodies require JSON when present.
- JSON bodies are size-bounded, reject unknown fields and reject trailing JSON.
- API responses use `Cache-Control: no-store`; CSP, MIME, frame, referrer,
  opener and browser permissions headers cover successes and errors.
- Oversized request URIs are rejected and handler panics return a generic 500.
