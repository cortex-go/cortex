# CX05 - Provider credentials and configuration

Threat: configuration corruption, permissive files, identifier injection or subprocess diagnostics disclose provider credentials.

Invariant: settings are bounded, valid JSON and owner-only; corrupt state fails startup without replacement. Provider/model values reject controls, key material is bounded, and all configured API/OAuth secrets are redacted from subprocess failures.

Evidence: focused tests cover file mode, corrupt recovery, multi-secret redaction and hostile identifiers. Full test, race, vet and build gates passed.

Retained boundary: API keys remain encrypted only by host filesystem access controls. A process with the Cortex account's authority can inspect its memory and environment.
