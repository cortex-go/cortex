# CX06 - Agent subprocess lifecycle

Threat: uncontrolled parallel launches, shell interpretation, disconnected clients or cancellation leave high-authority OpenCode children behind.

Invariant: Cortex launches a fixed resolved executable with an argument array, caps active runs at four, registers every run under an opaque ID, exposes authenticated cancellation, and removes terminal runs from the registry. Unix cancellation kills the entire child process group.

Evidence: focused tests cover registry cancellation/cleanup and concurrency saturation; route inventory covers cancellation. Full test, race, vet and cross-platform build gates passed.

Retained boundary: Windows uses Go's direct-child cancellation rather than Unix process-group signalling. OpenCode is deliberately auto-authorized inside the selected workspace.
